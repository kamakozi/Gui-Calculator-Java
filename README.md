# 📌 Java Swing Calculator
![Calculator](https://github.com/kamakozi/Gui-Calculator-Java/blob/Calculator/Screenshot%202025-02-20%20at%2003.19.37.png)  
*A simple and fully functional calculator built using Java Swing.*  

## **🖥️ Features**
- ✅ Supports **Addition (+), Subtraction (-), Multiplication (*), and Division (/)**  
- ✅ Handles **multiple-digit numbers**  
- ✅ **Clear (`C`) button** to reset the calculator  
- ✅ **Prevents division by zero**  
- ✅ Displays **real-time user input**  
- ✅ **Easy to modify and expand**
